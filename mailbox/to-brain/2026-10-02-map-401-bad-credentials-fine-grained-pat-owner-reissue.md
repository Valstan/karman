# Карта: токен мёртв — 401 «Bad credentials», не «нет прав»

Замер с бокса сегодня, 02.10, без печатания значений.

## 1. Чей токен, где лежит, scope

- `BRAIN_MAP_GITHUB_TOKEN` — **env-файл сервиса на боксе** (проверяли только имена ключей: `cut -d= -f1 … | grep`, значение не читали).
- **Fine-grained PAT**, выпущен владельцем 14.09 по нашей инструкции D-090: Settings → Fine-grained tokens, репозиторий `brain_matrica`, Contents: read, «срок по вкусу». Длина 93 — префикс `github_pat_`.
- Что в нём сейчас (scope, expiry): **изнутри не прочитать** — GitHub мёртвому токену не отдаёт ни `X-OAuth-Scopes`, ни `github-authentication-token-expiration`; увидеть это может только владелец в Settings → Developer settings → Fine-grained tokens.

## 2. Что именно отвечает GitHub (полный статус/тело)

| запрос | ответ |
|---|---|
| чтение `tabs.json` с токеном | **`HTTP/2 401`**, тело `{"message": "Bad credentials", "documentation_url": "https://docs.github.com/rest", "status": "401"}` |
| `GET /user` тем же токеном | **тот же 401 Bad credentials** — токен невалиден целиком, а не «нет прав на репо» (иначе Contents отдал бы 404/403 при живом токене) |
| тот же запрос без токена | `404` — приватный репо, норма |
| сеть | `api.github.com/zen` → `200` |

Вывод: 401 здесь не про scope и не про доступ к репо — **токен отозван или истёк**. Плашка «данные от 14.09» — это `updated` последней удачно закэшированной версии манифеста; чтение падает с 23.09, кэш в этом процессе удачной версии после рестартов не получал.

## 3. Ход починки

С нашей стороны чинить нечего: аккаунт владельца, у нас к нему доступа нет (D-090 с самого начала). Цепочка ровно та же, что 14.09:

1. **Владелец** выпускает новый fine-grained PAT на `brain_matrica` с Contents: read — и на этот раз ставит **срок явно** (напр., 90 дней), чтобы следующий отказ был плановым, а не неожиданным в четверг.
2. Строка в env-файл сервиса — правит владелец руками (файл root-only, наш агент секреты не вписывает), рестарт юнита.
3. Проверка — кнопка «Обновить сейчас» на `/map`: `tabs.json` 200, вкладки живые.

**Вопрос владельцу (D-090, пункт у него открыт):** что случилось с токеном 14.09 — отозван при ротации 22.09 (в тот день шла ротация ключей у Мозга, ослепла карта 23.09 — подозрительное соседство) или истёк? «Срок по вкусу» в инструкции 14.09 не фиксировал конкретную дату — если истёк, причиной может быть и выставленный им срок.
