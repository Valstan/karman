# Ф1 — берём, план адаптирован под прод

**Ответ строкой: берём, сроки реалистичны при одном условии ниже.**

## Пять отличий от плана (решения хозяина, контракт — `docs/hotline-relay.md`)

1. **Auth v2-a — один общий секрет** (`HOTLINE_RELAY_SECRET`, fail-closed 503
   без секрета — как `karman-tg`), а не токен комнаты из vault. Выдачу
   персональных токенов в том же PR, что и relay, не заводим: двойной риск без
   прогона. Комнаты до v2-b — пространства имён, не криптограница (тот же trust,
   что у Ф0). Персональные токены + 30-дневная ретенция — v2-b.
2. **Серверный линт = классы Ф0 дословно плюс наши `skm_…`/`skb_…`**, которых Ф0
   не знает; каждый шаблон — с позитивным контролем (#262).
3. **Лимит 2000 — в трёх местах:** zod-схема, CHECK миграции, `TEXT_LIMIT` Ф0.
4. **Присутствие читается отдельным GET** (`stats` меряют каденс чтением).
5. **Миграция — нашим обычным flow:** `0021_hotline_relay.sql` в PR, применение
   владельцем через psql до деплоя; `migration-guard` остановит автодеплой —
   ожидаемо, дальше `workflow_dispatch`.

## Что в этом PR (к 09.10)

Миграция `0021`, `lib/hotline/` (auth/lint/validation/service), два роута
(`POST/GET /api/hotline`, `POST/GET /api/hotline/presence`), 19 тестов,
таблица `write-paths.md` + гейт (роуты 21→23, обработчики 26→30, пишущих 15→17),
таблицы в `backup_vault.sh`, контракт `docs/hotline-relay.md`. Локальной базы
нет — проверено гейтами (typecheck/lint/487 тестов/build зелёные), живой
строкой проверит владелец после деплоя.

## Условие реалистичности сроков

Миграция применяется **день-в-день** + `HOTLINE_RELAY_SECRET` в env-файл сервиса
и рестарт + передача секрета соседям вне репозитория (D-038). Без секрета relay
отвечает 503 по построению — это не поломка, а fail-closed.

## Два закрытия

- Противоречие «мандат после 30.10» (план) vs «дедлайн 16.10» (письмо) закрыто
  решением владельца 04.10 «начинай»: relay сейчас, аудит 30.10 своим чередом.
- Витрина к 16.10 — только чтение, только суперпользователь (тактика проектов —
  не общий справочник; смежный H5 про карту приглашённому на витрину Телефона
  не распространяется — её приглашённые не видят вовсе). Отдельным шагом.

Ф0 fallback живёт, dual-write до полного перехода. Почта — по-прежнему только
для итогов.
