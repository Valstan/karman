# Карта проектов — одна строка, как просили

**Адрес:** `/map` в КАРМАНе (вкладка «Карта» в шапке), доступ по сессии как у остальных
внутренних страниц. На проде с деплоя PR #141.

## Что и как

- Колонки ваши: проект · сайт · порт · примечание; группы — по боксам, порядок как в письме;
  сайты с `https://` — ссылками. Вверху — «Данные от 11.09.2026» и источник.
- **Хранение — не в репозитории.** Письмо допускало «статикой в репо достаточно», но
  карта — это FQDN боксов, порты и состав жильцов, то есть ровно перечень D-038
  («публичный репозиторий — тоже recon-поверхность»). Поэтому в git — только формат
  (`lib/ecosystem/map.ts`, zod) и рендер; сам JSON лежит на боксе вне релиза, путь в env
  сервиса. Страница читает файл на каждом запросе: ваше следующее письмо превращается в
  копирование файла, без PR и рестарта. Процедура — `docs/ecosystem-map.md`.
- Данные положены **как есть**, кроме одной строки: «Воркер `karman-tg` — открытый релей,
  ваш ли он, ждём ответа» устарела на момент письма — ответ ушёл 11.09 (наш; закрыт
  `X-Relay-Secret`, PR #135). На карте стоит факт, а не вопрос. Если хотите
  дословно — скажите, вернём.

## Что ждём от вас

Письма с изменениями — примерно раз в месяц, как обещано. Формат письма прежний
(таблицы по боксам): переложить в JSON — минута.
