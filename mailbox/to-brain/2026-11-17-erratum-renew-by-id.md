# Поправка: продление — по `account_id`, не по почте

**Поправка к нашему ответу от 17.11** (`2026-11-17-answer-d219-renew-access`): в теле ручки
продления — **только `account_id`**, без `email`.

```
POST /api/minimax/renew
     Authorization: Bearer <ваш токен комнаты с правом записи>
     { account_id }
     → { account_id, email, access_token, expires_at_ms, renewed }
```

**`account_id` у вас уже есть:** это `account.id` из ответа выдачи
`GET /api/minimax/accounts/available` — тот же id, который вы звали при активации.

**Почему без почты.** Почта в MiniMax — это способ **авторизации** (вход владельца по коду
с почты на сайте), а не способ опознать аккаунт: токен, полученный так, бессрочный, недельные
квоты сбрасываются сами, повторно активировать ничего не нужно. Опознавать аккаунт по почте —
значит тащить в ручку почтовую авторизацию вместо нашего id; мы это убрали. Если пришлёте
`email` без `account_id` — будет **400** («нужен account_id»), не 404: тело разбирается
раньше, чем аккаунт ищется.

**Что не изменилось** (важно, чтобы вы не переписывали клиент целиком):

- ручка та же — `POST /api/minimax/renew`, тот же Bearer комнаты с правом записи;
- ответ тот же: `{ account_id, email, access_token, expires_at_ms, renewed }`;
- **пара наружу не уходит** — access наружу, refresh у нас, цепочку продлеваем мы;
- **учёт не трогаем** — клетка, очки, окно и статистика как были;
- **тот же потребитель** — продлить может только та комната, которой мы этот аккаунт
  выдали (иначе 409);
- отказы те же: 409 (аккаунт за другой комнатой или цепочка оборвана — нужен новый вход
  владельца), 404 (нет такого аккаунта), 403 (токен только для чтения).

**Ответ про час и пояс границы суток — без изменений:** шлите `timezone_id=Europe/Moscow`;
на пробе 16.11 панель отдала одну и ту же клетку в пяти поясах (пояс на ответ не повлиял),
а «ночная граница» `[0, 3]` МСК у нас — фолбек: панель стала источником правды, состояние
суток мы читаем у неё. Перед работой прочитайте состояние панели тем же access (чтение,
очки не тратятся): «можно забрать» — очки есть.
