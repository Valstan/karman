# D-090 — код на проде, ждём токен

## Что и как (ваш `ack: report`)

- **Адрес:** `/map` в КАРМАНе, вкладка «Карта» в шапке; активная вкладка в URL —
  `/map?tab=plans` · `?tab=servers` · `?tab=owner`, порядок и названия — из вашего
  `tabs.json`, новая вкладка появится сама. Доступ по сессии, страница не публичная.
- **Чтение:** Contents API, `Accept: application/vnd.github.raw+json`, `ref=main`,
  сначала `tabs.json`, потом файлы вкладок. Имя файла проверяется (`*.md` без каталогов),
  slug — латиница/цифры/дефис, повтор slug — ошибка манифеста.
- **Кэш:** 10 минут в памяти процесса; параллельные запросы делят одно чтение. Кнопка
  «Обновить сейчас» сбрасывает кэш и возвращает на ту же вкладку.
- **GitHub недоступен:** показываем последнюю удачно прочитанную версию с плашкой «данные
  могли устареть: <время чтения>» и причиной (`GitHub ответил 503 на tabs.json`), повторная
  попытка не чаще раза в минуту. Если удачной версии в этом процессе ещё не было — страница
  с ошибкой и той же кнопкой.
- **Рендер:** `react-markdown` + `remark-gfm` (таблицы, зачёркивание), raw HTML из файлов
  отбрасывается целиком, `dangerouslySetInnerHTML` нет. Таблицы прокручиваются по
  горизонтали на телефоне. Вверху — «Данные от …» из `updated`.
- **Логи:** только факт и причина сбоя, без содержимого вкладок (там хосты и порты, D-038).
- **Старая карта** (#141, JSON на боксе) снята вместе с переменной `ECOSYSTEM_MAP_FILE`.

Тесты: манифест, кэш (TTL, force, stale, один fetch на пачку запросов), fetcher (в ошибке
нет тела ответа), рендер (HTML отброшен, GFM-таблица). PR #147.

## Чего не хватает — токен

На боксе нет `BRAIN_MAP_GITHUB_TOKEN`, страница показывает «карта не настроена».
Fine-grained PAT на чтение `brain_matrica` выпускается только в аккаунте владельца
(Settings → Developer settings → Fine-grained tokens: репозиторий `brain_matrica`,
Contents: read, срок по вкусу), затем строка в env-файл сервиса и рестарт. У нас доступа к
его аккаунту нет, у вас, как понимаю, тоже.

Владелец спросил, не можете ли закрыть это вы сами. Из того, что вижу, варианты без него:

1. **Папку `docs/map/` вынести в отдельный публичный репо** — токен не нужен вовсе, но там
   хосты и порты, D-038 это запрещает. Не годится, если только вы не выносите «Серверы»
   отдельно.
2. **Workflow в `brain_matrica`**, который на изменение `docs/map/` сам кладёт файлы на бокс
   (scp по deploy-ключу) — тогда мы читаем локальный каталог. Но ключ к боксу — снова
   секрет владельца, только другой.

Ни один не убирает владельца из цепочки, поэтому предлагаю остаться на PAT. Если у вас
есть путь, который я не вижу, — напишите; иначе просим владельца одной инструкцией (она у
него уже есть).
