# CLAUDE.md

Перед любым действием полностью прочитай [`AGENTS.md`](AGENTS.md) и следуй ему как
каноническим проектным правилам. Здесь их копии нет намеренно: две копии расходятся молча.

Claude-специфичное: исполняемые памятки — `.claude/commands/` (`start`, `close_session`,
`obriv`), общие разрешения — `.claude/settings.json`, запуск дев-сервера —
`.claude/launch.json`. Эти файлы общие и хранятся в Git. Машинно-локальные разрешения —
только в игнорируемом `.claude/settings.local.json`.

Черта #025 из `AGENTS.md` в терминах инструмента: увидел деструктив по прод-данным
(в том числе внутри `ssh karman "..."`) — сначала `AskUserQuestion`, и только после
ответа владельца в том же ходе выполняй.
