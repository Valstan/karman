## MiniMax — пул: сторож возврата и прежние правила (18–19.11) — закрыто 20.11

**Утренний забор бонусов (заказ владельца 18.11).** PR #354, миграция `0035`: леджер
`accounts_daily_bonus` + роут `/api/internal/minimax/daily-bonus` (воркер зовёт в 05:00 МСК). Забор
(`signin/claim`) очки начисляет, а не тратит → серия не рвётся. Живой обход 18.11: 116 аккаунтов,
забрали 105, в банке 64 400 очков.

**Продолжения 18.11.** PR #356: две кнопки выдачи («Выдать 400-очковый (N)» / «Выдать
1000-очковый (M)», нет класса — «На сегодня закончились»), атрибуция по запрошенному проекту
(`X-MiniMax-Project`), статистика страницы. PR #358 — корень жалобы «выдали аккаунты с
потраченными очками»: **панель остатка очков не показывает** (`points` клетки = её номинал), а
клетку вендора сдвигает только день использования → признак один, `claim_result` из леджера. Убраны
кнопка «Сверить сутки», роут `panel-sync` и опрос панели по всем аккаунтам (≈21 000 обращений к
MiniMax в сутки); страница перестроена.

**Сторож возврата (18.11 → снят 20.11).** По мадату владельца: аккаунты, отданные потребителю,
сторож проверял по леджеру и возвращал в оборот (забрали мы → в оборот; забрал потребитель →
список погашенных на сегодня). Живая находка 19.11: **возврат в оборот и сортировка вместе давали
волну повторных выдач** — снятая отметка сессии делала аккаунт «никогда не активированным», он
вставал в начало очереди и уходил следующему потребителю уже без очков (19.11: **51 повторная
выдача из 104**, журнал лечащего: `ОТКАЗ ПО ОЧКАМ (insufficient balance (1008))`). Заказ владельца
19.11 (ночь): «Сторож который каждые полчаса возвращал аккаунты в пул, удали его совсем» — снят
совсем (сервис, роут, вызов из воркера, курсор). Сверка журнала с панелью (пункт «раз в полчаса»)
тоже снята — по этой же причине.

**Снятые подпункты.** (а) «правка сверки по первой ночи» — сверки больше нет. (б) «тысячные в
комнате `brain` при пустом пуле — решение владельца» — решено заказом 19.11 (ночь): тысячная
карусель — исключительно программированию, остальным четырёхсотковая; когда тысячная кончилась,
программирование переходит на неё.
