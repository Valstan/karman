## Failed approaches (этой нитки)

- **Бокс недоступен с машины агента:** ни `~/.ssh`, ни алиаса `karman`, ни ключа. Ключ
  деплоя есть только в секретах Actions. Значит «прогнать на проде из сессии» = отдельный
  узкий воркфлоу с зашитой командой (PR #240, PR #246), а не ssh руками.
- **Пароли нельзя передать в репозиторий** (он публичный): ни файлом, ни скриптом-сеятелем,
  ни входом workflow'а — **входы workflow'а видны всем, кто читает репозиторий**. Рабочий
  путь: человек вводит список в браузере → HTTPS → сервер шифрует мастер-ключом. Отсюда и
  функция импорта в самом разделе.
- **PowerShell 5.1 портит кодировку файлов** (`Get-Content | Set-Content` без `-Encoding`):
  страница раздела стала двоичным мусором (11 909 байт NUL). Лечится откатом из индекса и
  правкой инструментом записи; в этом репозитории файлы правим только так.
- **Squash-merge дописывает номер PR к теме:** если номер был в теме — получается
  «(#239) (#239)» в коммите на `main` (так и вышло в `72ae12d`). Лечится только на будущее:
  **в теме PR номер не указывать**, его добавит GitHub. Историю `main` не переписываем.
- **Ретенция, которая чистит всё вместо среза** (найдено боевым прогоном 03.11): считалось
  `count - keep`, а цикл шёл по всему списку — свежий архив удалялся сразу после «ГОТОВО».
  Общий класс: «шаг отработал» ≠ «результат на месте», и уборка не должна быть тем же
  проходом, что и создание.
