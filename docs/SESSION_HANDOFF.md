## Текущая нитка

_Нет — сессия закрыта._ Заказ владельца 05.11 в разделе «Минимакс» выполнен целиком
(PR #258 → `5796ee7`, PR #260 → `5428687`, оба на проде):

1. **Токены в плавающем окне не сохранялись.** Кнопка «Активировать этот аккаунт»
   уходила в сервер **без токенов** (`activateAccountOnly(account.id, projectId)`), и
   введённое число молча пропадало: ни в аккаунте, ни в журнале, ни в статистике.
   Теперь токены идут третьим аргументом; пустое поле — «не меняю».
2. **Активированных аккаунтов в списке 10 → 5** (`ACTIVATED_PREVIEW_LIMIT`), остальные
   — по кнопке «показать все аккаунты».
3. **Строка аккаунта** показывает: название, почту, обратный отсчёт **и дату**
   освобождения («· освободится 06.11 14:20», московское время), на какой проект
   активирован, сколько токенов ушло за активацию, сколько раз активировали за всю
   историю и сколько токенов суммарно. То же — в верхнем слоте.
4. **«Суммы по дням»** — день → активации, разные проекты, токены. По умолчанию
   последние **5 календарных дней** (дни без активаций — ноль), кнопка открывает всю
   историю, сортировка кликом по любой из трёх колонок.
5. **«Активации по дням»** — по умолчанию последние **3 дня**, кнопка — вся история.
6. **«Рейтинг аккаунтов»** — топ-10 по числу активаций + токены на них.
7. **«Активность по дням»** — кривая за 90 дней своим SVG, переключатель
   «активации / токены», дни без активаций — ноль.
8. **Список проектов отсортирован по частоте** — в диалоге активации, правке
   аккаунта и плавающем окне чаще всего используемые проекты сверху (число
   активаций → токены → название). Справочник проектов (чипы) не тронут.
9. **Токены по умолчанию 400** — поле подставлено готовым
   (`DEFAULT_ACTIVATION_TOKENS`), вводить одно и то же каждый раз не надо.

Счёт по всем этим цифрам идёт по журналу `accounts_usage`, а не по текущему состоянию
аккаунтов: у аккаунта хранится только последняя активация, а по дням и по рейтингу
нужна вся история. Вся арифметика — **чистые функции** `lib/accounts/stats.ts`
(`aggregateDailyUsage`, `fillDailySeries`, `sortDailyUsage`, `rankAccounts`,
`sortProjectsByUsage`), они же покрыты юнит-гейтом: числа на экране и числа в гейте
считаются одним кодом.

  активаций» = «сколько аккаунтов активировано» за день. В рейтинге то же самое —
  сколько ДНЕЙ брали аккаунт.
