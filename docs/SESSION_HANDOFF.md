## Failed approaches (этой нитки)

- **«Пара протухла — нужен новый вход»** — наша выдумка, из-за которой 84 пары выпали из
  оборота. Refresh у MiniMax одноразовый, но вместе с новым access вендор отдаёт новый
  refresh: цепочка продлевается (живая проба 15.11 — HTTP 200, пришли оба токена).
- **«24 часа от активации» как граница** — грубо: аккаунт, активированный в 23:50, ждал бы
  целые сутки, хотя сброс ночной. Заменено ночной границей (`DAILY_RESET_HOURS`).
- **Отдача пары целиком** (access + refresh) — отменена мандатом владельца 15.11: наружу
  уходит один access за запрос, refresh остаётся у нас.
- **Правка текстов точечными заменами по всему файлу** — в этом репозитории файлы CRLF,
  длинные русские строки в таких правках ломаются (битый символ → «0 вхождений»).
  Рабочий приём: правка по номерам строк скриптом + `git diff` на проверку.
