## Прод-инфра (для следующей сессии)

- **ssh:** алиасы `karman` и `GONBA`. Первый коннект может отвалиться по таймауту — повторить.
  Деструктив по прод-БД — только с подтверждением владельца в том же ходе (#025).
- **Порт приложения — 3002**, в юните, не в env-файле. Env-файл сервиса — см.
  `EnvironmentFile` юнита; там же `TELEGRAM_API_BASE` (реле) и `TELEGRAM_RELAY_SECRET`.
- **psql по ssh (D-046):** SQL в файл, на бокс через `ssh karman 'cat > /tmp/<файл>' < <файл>`
  (scp иногда рвётся), затем
  `ssh karman 'envf=$(systemctl show karman -p EnvironmentFiles --value | cut -d" " -f1); set -a; . "$envf"; psql "$DATABASE_URL" -f /tmp/<файл>'`.
  `\pset pager off` первой строкой; в `secrets_audit` колонка времени — `at`.
- **`gh`/`git` к GitHub с машины владельца рвутся TLS-таймаутом каждый ~3-й вызов** — всё
  сетевое в цикл повторов; мерж проверять `gh pr view N --json state`, не кодом возврата.
  Авто-мерж в репо **не включён** — `gh pr merge --squash` руками по зелёному.
- **Фоновые цепочки без `git checkout`:** цепочка «watch → merge → checkout main → pull»
  дважды за 11.09 переключила дерево под создаваемой веткой, коммит лёг на локальный
  `main`. `checkout`/`pull` — только в foreground перед новой веткой. Лечение без потерь:
  `git branch -f <ветка> <sha>; git reset --hard origin/main; git checkout <ветка>`.
- **`npm audit fix --omit=dev` сносит dev-пакеты из `node_modules`** — после него `npm install`,
  иначе typecheck/lint падают на отсутствующих бинарях.
- **Claude in Chrome** на этой машине рвётся, когда окно Chrome не в фокусе/свёрнуто;
  `browser_batch` роняет соединение — одиночные вызовы. Вставка кода в Monaco — только
  через буфер обмена (`computer-use` `write_clipboard` + `ctrl+a ctrl+v`), набор искажает скобки.
- **Локальной базы на этой машине нет** — проверять сборкой, тестами, гейтом маршрута.
- **`main` защищён:** required check `gates`, PR обязателен, `enforce_admins`.
- **Миграции:** guard блокирует авто-деплой → psql → `gh workflow run deploy-prod.yml --ref main`.
  Легаси-таблицы Django-эпохи принадлежат роли `postgres`: `ALTER` на них —
  `db=${DATABASE_URL##*/}; sudo -n -u postgres psql -d "${db%%\?*}" -f /tmp/<файл>`.
- **Бэкап vault:** cron 03:30, `scripts/backup_vault.sh`; список таблиц догнал схему в #123.
