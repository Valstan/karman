# Карта проектов (`/map`) — вкладки из репозитория Мозга

Решение владельца **D-090** (письмо Мозга 2026-09-12
`d090-project-map-page-with-tabs-read-from-the-brain-repo`): страница «Карта проектов» —
это вкладки (сегодня: Планы · Серверы · Дела владельца), содержимое которых **Мозг правит
напрямую в своём репозитории**, без браузера. КАРМАН содержимое не хранит и не правит —
только читает с GitHub и показывает. Это заменило первую редакцию (письмо 11.09, #141:
JSON-файл на боксе, `ECOSYSTEM_MAP_FILE`) — тот механизм снят, переменная больше не читается.

## Источник

Папка `docs/map/` в `Valstan/brain_matrica` (приватный репо), ветка `main`:

- `tabs.json` — `{ "updated": "ГГГГ-ММ-ДД", "source", "tabs": [ { "slug", "title", "file" } ] }`.
  Порядок вкладок — как в файле; новая вкладка появляется сама.
- `plans.md`, `servers.md`, `owner.md` — Markdown вкладок (заголовки, таблицы, списки; без HTML).

Схема манифеста и чтение — `lib/ecosystem/brain-map.ts`; рендер — `app/(app)/map/page.tsx`
и `components/map/markdown.tsx`.

## Токен

Чтение идёт через GitHub Contents API (`Accept: application/vnd.github.raw+json`) с
**fine-grained PAT владельца только на чтение**: один репозиторий `brain_matrica`,
разрешение Contents: read, больше ничего. Токен живёт в env-файле сервиса на боксе как
`BRAIN_MAP_GITHUB_TOKEN` (тем же путём, что остальные секреты — комната `karman`); Мозгу он
не нужен и не показывается. Без переменной страница показывает «карта не настроена».

Первичная установка: добавить `BRAIN_MAP_GITHUB_TOKEN=<pat>` в env-файл сервиса
(`EnvironmentFile` юнита), перезапустить сервис или дождаться ближайшего деплоя.
`ECOSYSTEM_MAP_FILE` из env можно убрать, файл `ecosystem-map.json` с бокса — удалить.

## Поведение

- **Кэш 10 минут** в памяти процесса; параллельные запросы делят одно чтение.
- Кнопка **«Обновить сейчас»** сбрасывает кэш и перечитывает (server action, только чтение).
- **GitHub недоступен** → показывается последняя удачно прочитанная версия с плашкой «данные
  могли устареть: <время чтения>» и причиной; повторная попытка — не раньше чем через минуту.
  Если удачной версии в этом процессе ещё не было — страница с ошибкой и той же кнопкой.
- **Рендер безопасный:** `react-markdown` + `remark-gfm`, raw HTML из файлов отбрасывается,
  `dangerouslySetInnerHTML` не используется. Таблицы прокручиваются по горизонтали.
- **Активная вкладка — в URL:** `/map?tab=servers`; неизвестный slug → первая вкладка.
- **Доступ:** любая залогиненная учётка, как у остальных внутренних страниц. Не публичная.
- **Логи** — только факт и причина сбоя (`[map] карта Мозга не прочитана: …`), без
  содержимого вкладок: там хосты и порты (D-038).
