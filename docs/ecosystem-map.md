# Карта проектов (`/map`) — какой сайт на каком боксе

Решение владельца 2026-09-11 (письмо Мозга `2026-09-11-a-map-of-the-ecosystem-page-…`):
карта экосистемы живёт в КАРМАНе отдельной страницей. **Единственный источник данных —
Мозг.** КАРМАН данные не проверяет и не дополняет: расхождение с реальностью — письмо Мозгу,
а не правка на месте. Обновления приходят письмами примерно раз в месяц и внепланово при
переездах.

## Почему не статика в репозитории

Письмо допускало «статикой в репо достаточно», но содержимое карты — FQDN боксов, порты,
состав жильцов — ровно то, что [D-038] (`AGENTS.md`, «Координаты боевой инфраструктуры»)
запрещает класть в отслеживаемые файлы публичного репозитория. Поэтому в git живут только
формат (`lib/ecosystem/map.ts`) и рендер (`app/(app)/map/page.tsx`), а сам JSON лежит
**на боксе вне репозитория**. Путь задаёт env `ECOSYSTEM_MAP_FILE` в env-файле сервиса
(см. `EnvironmentFile` в systemd-юните). Без переменной страница показывает «карта не
настроена»; битый файл — «файл не читается» с причиной. Файл читается при каждом запросе,
рестарт после обновления не нужен.

Доступ — как у остальных внутренних страниц: любая залогиненная учётка. Страница не
публичная и не индексируется (`(app)`-layout требует сессию).

## Формат файла

```json
{
  "asOf": "2026-09-11",
  "source": "письмо Мозга 2026-09-11",
  "groups": [
    {
      "title": "Бокс 1 — <host>",
      "subtitle": "хостер, тариф, БД",
      "rows": [
        { "project": "КАРМАН", "site": "внутренний", "port": ":3002", "note": "+ reminders-worker" }
      ]
    }
  ],
  "archive": "postopus, mikrokredit — репо на GitHub не удалены."
}
```

- `asOf` — обязательно, `ГГГГ-ММ-ДД`; показывается вверху как «Данные от …» (свежесть
  владелец видит сразу).
- `groups[].title` — обязательно; `subtitle`, `archive`, `source` и поля строк кроме
  `project` — необязательны, пустые показываются прочерком.
- `site`, начинающийся с `http(s)://`, рендерится ссылкой.
- Колонки страницы фиксированы: проект · сайт · порт · примечание (те, что просил Мозг).
  Группы — по боксам, порядок — как в файле.

## Обновление по письму Мозга

1. Сессия КАРМАНа собирает новый JSON **в scratchpad** (не в репозитории) из письма.
2. Проверка формата локально: `ECOSYSTEM_MAP_FILE=<путь> npm run dev` и открыть `/map`
   (локальной БД на машине владельца нет — тогда проверка сразу на проде, шаг 4).
3. Копирование на бокс (scp иногда рвётся — D-046):
   `ssh karman 'cat > /tmp/ecosystem-map.json' < <файл>`, затем
   `ssh karman 'envf=$(systemctl show karman -p EnvironmentFiles --value | cut -d" " -f1); set -a; . "$envf"; cp /tmp/ecosystem-map.json "$ECOSYSTEM_MAP_FILE"'`.
4. Признак: страница `/map` показывает новую дату «Данные от …». Рестарт не нужен.
5. Ответ Мозгу по `ack:` письма, если он запрошен.

Первичная установка: положить файл на бокс, добавить `ECOSYSTEM_MAP_FILE=<путь>` в env-файл
сервиса, перезапустить сервис (или дождаться ближайшего деплоя — он делает restart).
